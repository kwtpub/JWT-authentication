# Security policy

This repository is an educational AppSec case study. Only the current default branch receives fixes. The documented baseline is intentionally vulnerable historical source, and its reproduction runner is intended for local synthetic data only.

If you find another issue, send a minimal reproduction to **kwtd6v@proton.me**. Please do not put real credentials, tokens, or personal data in a public issue.

The case study documents the review scope, test environment, and remaining limitations. It does not certify any deployed instance.
